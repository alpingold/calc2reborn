# Problem types

The closed list of problem types for each lesson, drafted from the lesson's key ideas and every exam question tagged to it. A question gets one or two of these when its solution is written; mastery, the Today plan and "Try a similar question" all work from this list.

The count is how many of the lesson's current exam questions fit the type best. Review the names and the splits: once tagging starts, changing an id means retagging.
